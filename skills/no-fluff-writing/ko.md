# 한국어 부록

`SKILL.md` 의 계약에 한국어 글에서만 필요한 규칙을 더한다.

## 종결 (독자별)

| 독자 | 대상 | 종결 |
|---|---|---|
| 사용자 · 고객 | 화면 글, 안내, 릴리즈 노트, 사용자 대상 README | 합니다체 |
| 개발자 기록 | 코드 주석, 설계 문서, 커밋 메시지, 내부 문서 | 한다체 |

- 한 글 안에서 종결을 섞지 않는다. 해요체 · 반말 · 느낌표 · 이모지를 섞지 않는다.
- 나열의 가운뎃점(·)은 앞뒤를 띄운다. 「이메일 · 푸시」

## 쓰지 않는 표현

| 쓰지 않음 | 씀 |
|---|---|
| ~의 여정 · 첫걸음을 내딛다 | 시작 · 처음 설정 |
| 한 단계 더 나아가 · 새로운 차원의 | (뺀다) |
| 혁신적인 · 강력한 · 손쉽게 · 마법처럼 | (뺀다, 또는 측정값을 쓴다) |
| ~라고 해도 과언이 아닙니다 | (뺀다, 사실만 쓴다) |
| 주목할 점은 · 눈여겨볼 부분은 | (뺀다, 사실만 쓴다) |
| 단순한 X가 아닙니다 — Y입니다 | X입니다. Y도 합니다. |
| 함수가 깨어납니다 · 잠듭니다 · 쉽니다 | 함수가 실행됩니다 · 중지됩니다 · 비활성화됩니다 |
| 오류를 삼킵니다 | 오류를 출력하지 않습니다 |
| 데이터가 잠들어 있습니다 | 데이터가 저장되어 있습니다 |
| 이 모듈은 ~을 꿈꿉니다 · ~을 책임집니다 | 이 모듈은 ~을 합니다 |

표에 없는 표현도 `SKILL.md` 의 계약으로 판단한다. 실제 위치 · 접촉 · 동작을 말하는 표현(「화면 위쪽」 · 「성문에 닿은 벽」)은 쓴다.

## 화면 글

| 요소 | 형태 | 예 |
|---|---|---|
| 제목 · 라벨 · 탭 · 열 이름 | 명사구 | 「방해 금지 시간」 |
| 버튼 | 동작 명사나 짧은 동사 | 「저장」 · 「프로젝트 만들기」 · 「다시 시도」 |
| 사실 줄 | 합니다체 한 문장 | 「매일 02:00에 실행됩니다.」 과제 · 코드 · 명세에 있는 사실만 쓴다 |
| 상태 글(토스트 · 안내 · 빈 상태 · 오류) | 합니다체 평서문 | 「저장되었습니다.」 「프로젝트가 없습니다.」 |

| 쓰지 않음 | 씀 |
|---|---|
| 여정을 시작하세요 · 첫걸음을 내딛어 보세요 | 시작 · 프로젝트 만들기 |
| 아직 텅 비어 있어요 · 여기는 조용하네요 | 프로젝트가 없습니다. |
| 모든 준비가 끝났어요! | 저장되었습니다. |
| 이곳은 ~하는 공간입니다 · 이 섹션에서는 ~할 수 있습니다 | (뺀다) |
| 이메일 알림 (제목이 「알림」일 때) | 이메일 |
